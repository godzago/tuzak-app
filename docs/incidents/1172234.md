# 1172234 — toria.apple03cloudstore.com yanlış negatif incelemesi

İnceleme tarihi: 2026-09-25. İncelenen site açılmadı; yalnız resmi API sorgulandı.

## 1. API ve auth

Uygulamadaki gerçek `ThreatApiService.checkDomain()` ve
`ThreatEnrichedAnalyzer` kullanılarak, auth header olmadan şu istek yapıldı:

```text
GET https://siberguvenlik.gov.tr/api/address/index?q=toria.apple03cloudstore.com&type=domain&per-page=1
```

HTTP **200**, yanıt gövdesi:

```json
{"totalCount":1,"count":1,"models":[{"id":1172234,"url":"toria.apple03cloudstore.com","type":"domain","desc":"MD","source":"SB","date":"2026-09-24 14:24:56.841135","criticality_level":8,"connectiontype":"OT"}],"page":0,"pageCount":1}
```

Bu kaydın criticality değeri **8**, source değeri **SB**; 2 veya US değildir.
Sorguda `source=US` filtresi kullanılmıyor. 401/403 gözlenmedi. API'nin q
parametresi alt dize araması yaptığından tam host doğrulaması korunuyor.

İlk bağımsız PowerShell HTTP isteği 2972 ms sürdü. Uygulama servisinin sonraki
iki çağrısı 566/75 ms'de tamamlandı. İki saniye sınırı geçilirse API sonucu
bilinmiyor kalır. Cihazdaki asıl denemenin logları olmadığından o denemenin
timeout/offline/başka erişim hatasından hangisi olduğu kesinleştirilemez.

Debug logları artık çağrıyı, q/type/per-page değerlerini, HTTP durum/gövdesini,
süreyi, timeout/iptal veya auth hatasını gösterir. Release/profile'da assert
blokları çalışmaz. Header'lar, API anahtarı ve mesaj içeriği loglanmaz.

## 2. Host ayrıştırma

Çıkarılan tam host **toria.apple03cloudstore.com**. Bare domain, HTTPS,
büyük/küçük harf, sondaki nokta, userinfo, port, path, query ve fragment
senaryoları unit testle doğrulandı. Alt alan adı kesilmiyor; API'ye yalnız
host gidiyor. E-posta adresi URL olarak sorgulanmıyor. Parser kök neden değil.

## 3. Doğrulanan kök neden ve düzeltme

Önceki kurallarla yalnız alan adı: **low / 0.0 / noSignals**. Apple/iCloud
marka listesinde yoktu; ayrıca `apple03cloudstore` gibi bitişik parçalar tam
token veya edit-distance-1 eşleşmesine girmiyordu. `.com` riskli uzantı değil;
bu adreste yalnız `toria` alt alan adı var, derinlik kuralının tetiklenmemesi
normal. API dönmezse sıfır yerel skor düşük risk görünümüne dönüşüyordu.

API yanıtı alınsa bile eski birleştirme seviye 8 kaydı yalnız **Şüpheli**
yapıyordu. Bu doğrudan düşük riskin nedeni değildir, ayrı bir öncelik açığıdır.

Düzeltmeler:

- Global 9 marka grubu aktif `rules.json.brands` listesine eklendi. Aktif formatta
  ayrı brands.json kullanılmıyor.
- Marka + sayı/hesap/giriş/bulut/mağaza eklerinden oluşan tam parçalar tespit
  ediliyor. Bu adres yerelde **0.7525 / high**: brand_mismatch 0.55 ve lookalike
  0.45 (`1 - 0.45 * 0.55`). Adrese özel bloklama veya gerçek USOM verisi eklenmedi.
- Genel `deceptive_subdomain` sinyali bilinmeyen markaları da içeren yanıltıcı
  adres yapılarını yakalıyor; bilinmeyen marka sahipliği hakkında kesin hüküm
  vermiyor. Sıradan derin CDN adresleri, `pineapple` ve resmi siteler kontrol
  örnekleriyle test ediliyor.
- Her doğrulanmış API eşleşmesi en az **Yüksek risk**; criticality 1–3 hâlâ
  **Tehlikeli**. Yerel tehlikeli seviye asla düşürülmüyor.
- API kontrolü başarısız/kısmi ve yerel bulgu yoksa yeşil düşük risk başlığı
  yerine **Kontrol sınırlı** gösteriliyor. Gerçek ağ hatası kullanıcıya basılmıyor.

## 4. Regresyon doğrulaması

- `assets/test_cases.json`: bildirilen bare host ve Apple/iCloud mesajı için
  `scam / expect_min: high`; diğer global markalar ve meşru örneklerle 98 vaka.
- `reported_domain_test.dart`: tam host çıkarma, çevrimdışı yüksek risk,
  criticality 2 mock → Tehlikeli, gerçek seviye 8 fixture → Yüksek risk,
  iki saniye timeout ve marka listesi dışındaki adres yapıları.
- `threat_api_service_test.dart`: gerçek yanıt biçimi/type/source, debug log,
  401/403 ayrımı ve anahtarın logdan gizlenmesi.
- Son canlı kontrol: yerel **high / 0.7525**, HTTP **200**, `found=true`,
  `category=MD`, `criticality=8`, birleşik sonuç **high / complete**.
  İki sorgu 536 ms ve 74 ms sürdü.

Yeniden çalıştırma:

```sh
python tool/sync_analysis_assets.py
dart --enable-asserts run tool/diagnose_threat_api.dart toria.apple03cloudstore.com
flutter test
```

Yeni kurallar için uygulama yeniden derlenip kurulmalıdır; hot reload yeterli
değildir. Bildirilen alan adı açık tehdit göstergesidir; test mesajları gerçek
kullanıcı verisi içermez.

Doğrulama sonucu: 195 test geçti (isteğe bağlı görsel yakalama testi ayrıca
çalıştırıldı); `flutter analyze` temiz. `result-unverified.png` görünümü
incelendi. iOS gerçek cihaz doğrulaması bu Windows ortamında yapılmadı.
